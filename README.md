# CorrosionMLI1

Corrosion rate prediction (ML) project.

## Contents
- `Corrosion_Rate_Prediction.ipynb`: main analysis/training notebook
- `build_notebook.py`: helper script for notebook-related automation
- `synthetic_corrosion_ml_dataset.xlsx`: dataset used in the notebook
- `xgboost_model.pkl`, `scaler.pkl`, `feature_names.pkl`: trained artifacts
- `test_predictions.csv`, `val_predictions.csv`: saved predictions

## Quick start
1. Create a Python environment
2. Install dependencies required by the notebook/script
3. Run the notebook (`Corrosion_Rate_Prediction.ipynb`) end-to-end
